## Technical Stack

* **Framework**: Next.js 16 (App Router)
* **Styling**: Tailwind CSS
* **Protocols**: Model Context Protocol (MCP) Certified
* **Deployment**: Vercel Edge Network
* **SEO**: Dynamic Sitemap, Semantic JSON-LD Schema, AI Search Engine Directives (`GPTBot`, `ClaudeBot`, `PerplexityBot`)
* **Security**: HSTS, Strict CSP, No-Sniff, X-Frame-Options DENY, Ephemeral Headers

## Development & Build

```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev

# Production build
pnpm run build

# Start production server
pnpm run start
```
