# ArcaneTech

> **Intelligence applied to human problems.**

[ArcaneTech](https://arcanetechnologies.org) is a frontier artificial intelligence research and software laboratory. We engineer autonomous cognitive systems, multi-jurisdiction registry intelligence networks, and deterministic self-healing software (AppSec and OpSec) for the global economy.

## Technical Stack

* **Framework**: Next.js 16 (App Router)
* **Styling**: Tailwind CSS 4 · institute tokens (Void / Paper / Brass)
* **Motion**: [`motion`](https://motion.dev) (`motion/react`)
* **Protocols**: Model Context Protocol (MCP) Certified
* **Deployment**: Vercel Edge Network
* **SEO**: Dynamic Sitemap, Semantic JSON-LD Schema, AI Search Engine Directives (`GPTBot`, `ClaudeBot`, `PerplexityBot`)
* **Security**: HSTS, Strict CSP, No-Sniff, X-Frame-Options DENY, Ephemeral Headers

## Development & Build

```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev

# Production build
pnpm run build

# Start production server
pnpm run start

# Lint
pnpm run lint
```
